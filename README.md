# Projeto UX e Acessibilidade

Projeto desenvolvido como parte do curso da plataforma Start by Alura.

## 🚀 Tecnologias Utilizadas
- HTML5 Semântico
- CSS3 (Acessibilidade visual e foco visível)
- JavaScript (Manipulação do DOM e atalhos de teclado)

## ♿ Recursos de Acessibilidade
- Uso de marcações ARIA (`aria-haspopup`, `aria-hidden`, `aria-labelledby`).
- Gerenciamento de foco do teclado.
- Suporte à tecla `ESC` para fechar modais.
- Contraste de cores adequado para leitura.
